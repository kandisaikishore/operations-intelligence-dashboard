## Goals

- Make operational status and trends easier to inspect
- Document metric definitions and source data
- Distinguish exceptions from routine activity

## Getting started

```bash
git clone https://github.com/saikishore2410/operations-intelligence-dashboard.git
cd operations-intelligence-dashboard
```

Install dependencies and run the commands defined by the repository's framework and project manifest.

## Data quality and reliability

Before using the dashboard to make operational decisions, document data freshness, calculation rules, source-system access, permissions, and failure states. Never present sample data as live production metrics.
